Models and backends that actually run.

Four projects, each with its code on GitHub.

Fake News Detection System

  • Python
  • PyTorch
  • Hugging Face
  • PEFT (LoRA)
  • TinyBERT
  • Streamlit
  • TinyBERT-4L with LoRA, headline-to-body cross-attention and a Bi-GRU head, trained in two stages on a T4 GPU.
  • 99.36% accuracy and 0.9938 F1 on 14,308 held-out WELFake articles (72k-article dataset).
  • Streamlit app returns a verdict and confidence in about 1–2 seconds on CPU.

Agentic Payment Recovery (PayGuard-AI)

Prototype
  • Python
  • FastAPI
  • LLM function calling
  • Tenacity
  • Streamlit
  • A webhook receives failed payments; an LLM chooses retry, payment link or human escalation through function calling.
  • Exponential backoff with jitter, honours Retry-After, and auto-escalates when the model fails.
  • Streamlit dashboard of recovery metrics.
GitHub →

Quiz Leaderboard Service

  • Java 11
  • HttpClient
  • REST
  • JSON
  • Polls an external quiz API and de-duplicates score events with a HashMap keyed on round and participant.
  • Ranks with a custom Comparator and posts the leaderboard as JSON.
GitHub →

StreamFlix (Netflix Clone, Full-Stack)

  • React 19
  • Node.js
  • Express 5
  • Sequelize
  • PostgreSQL/SQLite
  • Firebase Auth
  • TMDB API
  • Vercel
  • Responsive Netflix-style web app: browse movies and TV by category, search, and play trailers.
  • Express backend proxies the TMDB API so the API key stays on the server; trailer lookup falls back from movie to TV endpoints.
  • Firebase email/password sign-in and a personal "My List" watchlist stored with Sequelize (SQLite locally, PostgreSQL in production).
